PoC 프로토타입구노 실제 CSS·아이콘을 그대로 사용합니다. 백엔드·DB 없음 — 업무 흐름을 보여주기 위한 화면 미리보기입니다.

Goono ELN → LIMS 확장 · 업무 흐름 미리보기

시료 하나가 접수되어 시험을 거쳐 규격 이탈 조사와 재시험까지 가는 한 줄기 시나리오를 화면으로 따라갑니다.
각 화면은 실제 구현된 Thymeleaf 화면과 같은 CSS·아이콘·클래스를 씁니다.

이 프로토타입이 아닌 것
· 백엔드가 붙어 있지 않습니다. 데이터는 고정값이고 입력·저장은 동작하지 않습니다.
· 실제 시스템은 Spring Boot(WAR) + MariaDB 로 동작하며, 이 프로토타입은 화면과 흐름만 떼어낸 것입니다.
· 화면에 적힌 규칙(채번·판정·권한)은 재단 확인 전 임시 결정입니다. 각 화면 하단에 근거를 적어두었습니다.
① 시료 접수

합성 원료를 접수하고 시료번호를 자동 채번합니다.

② 분주·계통

원 시료를 4개로 분주하고 계통을 남깁니다. 노트 역추적도 여기서 보입니다.

③ 시험 의뢰

분주본에 시험을 의뢰합니다. 의뢰 1건에 항목 여러 개가 붙습니다.

④ 담당자 배정

책임자가 미배정 항목에 담당자를 붙입니다. 배정이 곧 접수입니다.

⑤ 결과·판정

측정값을 넣으면 즉시 확정 저장되고 규격 대비 판정이 계산됩니다.

⑥ 규격 이탈 조사

부적합이 나면 조사가 자동 생성됩니다. 조사자는 입력자와 달라야 합니다.

⑦ 재시험

재시험 결과로 종결합니다. 원 결과와 재시험 결과가 둘 다 남습니다.
분석법·규격 마스터

버전 관리. 결과는 특정 버전에 묶입니다.

 장비·교정 관리

교정 만료 장비는 결과 입력을 차단합니다.
