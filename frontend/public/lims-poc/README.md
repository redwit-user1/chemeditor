# LIMS PoC 프로토타입 (정적 화면)

고객사 시연용 **업무 흐름 미리보기**다. 백엔드가 없고, 데이터는 고정값이며, 입력·저장은 동작하지 않는다.

## 무엇인가

시료 하나가 접수되어 시험을 거쳐 규격 이탈 조사와 재시험까지 가는 **한 줄기 시나리오**를 화면으로 따라간다.

```
① 시료 접수 → ② 분주·계통 → ③ 시험 의뢰 → ④ 담당자 배정
           → ⑤ 결과·판정 → ⑥ 규격 이탈 조사 → ⑦ 재시험
```

각 화면 상단에 진행 단계가 표시되고, 하단의 버튼이 다음 단계로 이어진다.
화면마다 "이 단계에서 무슨 일이 일어나는가"와 "왜 그렇게 설계했는가"를 적어 두었다.

## 구노 스타일을 어떻게 맞췄나

- 로고·GNB 메뉴 아이콘은 `src/main/resources/static/lib/eln/img/` 의 **실제 파일**을 그대로 쓴다.
- 메뉴 아이콘 CSS 규칙은 `lib/eln/css/lims.css` 에서 **원본을 발췌**했다(`css/proto.css` 하단).
- 색·타이포는 `style.css` 에서 확인한 토큰을 그대로 쓴다 — primary `#1761DE`, GNB navy `#08204A`,
  gray 900/700/600/300/50, danger `#EE5139`, radius 10px, Noto Sans KR.
- `style.css`(244KB) 자체는 싣지 않았다. 이 프로토타입은 실제 화면의 레이아웃 클래스를 쓰지 않고
  자체 클래스로 구성했기 때문에 기여하는 바가 거의 없고, 배포 페이로드만 키운다.

## 로컬에서 보기

```bash
cd docs/lims/prototype && python3 -m http.server 8080
# http://localhost:8080
```
