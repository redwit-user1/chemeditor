## Chem Service HTTP 실측 (Goono 프록시 전 단계)

> Goono ELN 통합(iframe ChemModal, Epic #23 / E4 #27) 대비, Chem Service 두 개
> write-path 엔드포인트의 **클라이언트 관측 HTTP 왕복 지연**을 실측한다.
> 위의 물성 계산 표(0.23 ms p50)는 백엔드 compute 함수 그 자체만 잰 값이고,
> 아래는 그 위에 얹힌 FastAPI + Uvicorn + 루프백 HTTP + JSON 직렬화까지 포함한
> 실제 요청 지연이다. 그 차이(≈0.2 ms → ≈1.6 ms)가 프레임워크·전송 오버헤드다.
>
> **주의: 이 수치에는 Goono 리버스 프록시 홉이 포함되지 않는다.** 이 샌드박스에서
> Goono(Spring Boot)를 빌드할 수 없어 프록시 구간은 측정 불가. 아래 값은 Goono
> 프록시가 얹힐 **하한(lower bound)** 이다. Goono 통합 후 프록시 포함 E2E는
> 별도 재측정이 필요하다.

측정 방법:
- 서버: `uvicorn app.main:app` (127.0.0.1, portable_fp 백엔드, 번들 fixture 7건 인덱스).
- 클라이언트: 동일 호스트 `httpx.Client`, 루프백. 재현 스크립트 `scripts/bench_http.py`.
- 물성: 워밍업 20회(3 구조 전체) 후 **구조당 200회**. 대표 구조 3종 —
  small(aspirin SMILES, 13 heavy) / medium(caffeine V2000 molblock, 14 heavy) /
  large(reserpine V2000 molblock, 44 heavy).
- 등록: 워밍업 20회 후 **100회**, 매 요청 고유 `reg_id`(라이브 인덱스에 실제 삽입).
- 백분위: nearest-rank. 환경: Python 3.11.15 · Linux x86_64 · RDKit 2026.03.3 ·
  FastAPI 0.139.0 · Uvicorn 0.51.0 · httpx 0.28.1.

# 배포된 프로토타입의 화면 비용 (2026-08-07 추가)

> 위까지는 **백엔드 계산**의 성능이다. 아래는 **재단이 실제로 여는 화면**의 비용이다.
> 둘은 다른 숫자이고, 현장에서 문제가 된 것은 아래쪽이었다.
>
> 측정: Chromium · 뷰포트 1440×1000 · 배포와 동일한 구조(`/lims-poc/` + `/editor`
> rewrite)를 로컬에 세워 계측. **네트워크 지연 0** 이므로 아래 값은 **하한**이다 —
> 실제 망에서는 더 걸린다. 배포 도메인은 본 작업 환경의 egress 정책에 막혀
> 직접 계측하지 못했다(정책 거부 403). 그 사실을 숨기지 않는다.

## 구조 편집기(Ketcher + RDKit WASM)가 쓸 수 있게 되기까지

| | 편집기 준비 신호(`chemeditor:ready`) |
|---|---|
| 첫 방문 (캐시 없음) | **5,252 ms** |
| 두 번째 방문 (캐시 있음) | **3,348 ms** |

캐시가 있어도 3.3초가 걸리는 것은 24MB 번들의 **파싱·WASM 초기화** 비용이다.
내려받기만의 문제가 아니다.

## 이 숫자가 만든 실제 장애

구조 입력기 화면은 편집기가 안 붙을 때를 대비해 RDKit 로 미리 그려 둔 구조로
대체하도록 되어 있었고, **그 판단 기한이 8초**였다. 위 표에서 보듯 지연 0 인
로컬에서도 준비까지 5.3초다 — 실제 망에서는 8초를 넘긴다.

그래서 재단에서 열었을 때 **아직 내려받는 중이던 편집기가 대체 화면으로
갈아치워졌다.** 사용자에게는 "구조는 그려져 있는데 입력이 안 되는" 화면으로
보였다(2026-08-06 신약센터 문의).

조치: 시간으로 실패를 단정하지 않는다. `load` 이벤트와 준비 신호를 기다리고,
기다리는 동안 사유(24MB · 경과 초)를 표시하며, 60초가 지나도 응답이 없으면
말없이 대체하지 않고 `다시 시도` / `등록된 구조로 보기` 를 사용자가 고른다.

## 무게의 출처

프로토타입 배포본 전체 **52 MB** (화면 24장 + 첫 화면·사용 안내서). 큰 것부터:

| 자산 | 크기 | 무엇 |
|---|---|---|
| `editor-ai/chunks/ChemModal-*.js` | 16 MB | 노트 편집기의 화학 모듈 |
| `editor-ai/chunks/dist-*.js` | 8.8 MB | 노트 편집기 본체 |
| `/editor` SPA `index-*.js` | 24 MB | Ketcher + RDKit WASM |
| `editor-ai/style.css` | 1.7 MB | 노트 편집기 스타일 |
| `adminlte.min.css` | 1.4 MB | 구노 ELN 기존 테마 |

**개선 여지(미구현, 설계만):** ① RDKit WASM 을 지연 로드해 그리기 시작 전까지는
받지 않는다, ② Ketcher 를 필요한 도구만 남겨 트리셰이킹, ③ 편집기 번들을
사전 캐시(Service Worker)해 두 번째 방문 이후를 0 에 가깝게.
셋 다 이번 PoC 범위 밖이며 파일럿 착수 시 다룰 항목이다.
